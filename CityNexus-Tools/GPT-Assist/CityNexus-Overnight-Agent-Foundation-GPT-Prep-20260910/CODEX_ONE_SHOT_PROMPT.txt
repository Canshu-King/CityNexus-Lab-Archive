9. Agent 不能修改自己的授权 policy。
10. payment/refund/C4 mutation 今晚不开放给 Agent 自动执行。

==================================================
G. Phase 4：Authorization Policy
==================================================

至少实现：

READ ACTION
-> ALLOW_AUTO

REQUEST_REPLAN
-> ALLOW_AUTO
因为只生成 proposal，不激活 Domain Truth。

ACCEPT_REPLAN：

如果 hard constraints != PASS
-> DENY

如果 C4 / locked commitment 没 preserved
-> DENY

ADVISORY
-> REQUIRE_CONFIRMATION

ASSISTED/AUTONOMOUS + auto_accept_replan=true：

只有同时满足：

- cost_delta_minor <= policy threshold
- provider evidence not degraded，除非 policy 明确允许
- event severity not CRITICAL，除非 policy 明确允许
- proposal still PRESENTED
- base plan still current
- trigger event still actionable

才可以 ALLOW_AUTO。

但即使 Policy ALLOW_AUTO，真正执行时仍必须调用现有 accept-time deterministic feasibility revalidation。

付款 / 退款 / 修改 C4：

今晚只定义 `REQUIRE_STEP_UP` 语义。
不要真正开放 MCP tool。
