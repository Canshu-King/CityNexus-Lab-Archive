# Real-City Control Tower

Upgrade the map from an overlay canvas to a real city operations view.

Use MapLibre with a real vector basemap.
A no-key development option is OpenFreeMap.

Show:
- actual streets/buildings/labels;
- active Journey route;
- proposed route;
- current Activity;
- upcoming protected Commitments;
- real discovered POIs;
- weather/risk areas;
- route exposure;
- resilience score;
- current Guardian/Agent state;
- provider provenance.

Optional visual flourish:
- 3D building style where supported;
- animated route transition after autonomous recovery;
- risk halo/polygon around affected areas;
- "before / after" route toggle.

Do not let the map become decorative.
The geometry and provider labels must match backend evidence.
