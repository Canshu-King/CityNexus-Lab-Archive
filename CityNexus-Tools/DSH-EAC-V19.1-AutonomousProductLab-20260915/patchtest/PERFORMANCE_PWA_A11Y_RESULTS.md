Notes:

- The shadow app contains no MapLibre/WebGL module.
- The PWA service worker and Workbox are generated by the existing
  `vite-plugin-pwa` dependency.
- The app shell has no second PWA framework.

## 2. PWA / offline

`shadow-app/vite.config.ts` uses `vite-plugin-pwa` with:

- `generateSW`;
- `v19-1-sw.js`;
- navigate fallback `/index.html`;
- `NetworkFirst` runtime caching for `/api/v1/` with a 3-second network timeout.

Offline truth is still enforced by the UI source layer: cached API data is
labelled `OFFLINE_STALE` with a `staleAt` timestamp and is never presented as
`LIVE_SHADOW`.

Build output:

```text

dist/v19-1-sw.js
dist/workbox-ee9d8b34.js
```

## 4. Critical state language

- `NEEDS_LIVE_EVIDENCE` uses a dotted badge, hourglass glyph, and explicit text.
- `UNVERIFIED` uses a dashed badge and question glyph.
- `CONFLICT` uses a double border and exclamation glyph.
- `VERIFIED` uses a solid badge and check glyph; it is never used for absent
  evidence.
- Unknown states are not expressed with colour alone.

## 5. Honest limits

- `overflow-x: clip` is used at the CSS zoom stress boundary to avoid document
  horizontal scrolling in the synthetic zoom test.  Real browser zoom still
  requires manual QA with the target browser.
- Axe is a machine-check gate; manual screen-reader validation is still
  recommended before production release.
- PWA service-worker behavior is validated in the isolated shadow app, not by
  modifying the main frontend registration.
