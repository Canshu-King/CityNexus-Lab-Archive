# Autonomy Charter

Harness EAC is allowed to find its own work inside the isolated lab.

It is NOT allowed to:

- modify `D:\moodle\CityNexus`;
- modify the user's main Hermes `citynexus` profile;
- use admin privileges;
- print/copy/package API keys;
- silently claim fixture data is live;
- invent accessibility/provider evidence;
- replace the product architecture with a second framework.

After mandatory workstreams are complete, Harness may independently select
additional improvements if they satisfy ALL of:

1. measurable user/product value;
2. evidence-backed problem;
3. isolated implementation;
4. low-conflict patch or clear handoff;
5. tests or reproducible proof;
6. no violation of CityNexus truth/authority boundaries.

Good autonomous targets:
- broken or misleading user flows;
- runtime/API contract drift;
- onboarding friction;
- mobile layout/performance;
- offline/stale truth;
- map usability;
- provider evidence visibility;
- accessibility;
- bundle/performance;
- state recovery;
- packaging/reproducibility;
- frontend observability.

Bad autonomous targets:
- renaming architecture for aesthetics;
- another Agent framework;
- another PWA framework;
- speculative database rewrite;
- large dependency additions without need;
- endless color/spacing polishing.
