## 使用规则

- 不要求逐像素复制。
- 信息架构、层级、主 CTA、卡片结构和移动端密度应尽量遵循。
- 字体、真实地图、真实图片可按现有技术栈实现。
- `DESIGN_CORRECTIONS_REQUIRED.md` 的修正规则优先于图片。
- 不能为了像图片而伪造后端没有的数据。
