# MORNING ACCEPTANCE GATE

## 必须 0 个 P0

P0 包括：

- 白屏
- 主导航死路
- 用户不知道下一步做什么
- 错城市地图
- 不可恢复页面
- 关键 CTA 看不见
- raw enum / internal code 直接暴露
- 行程修改造成与后端 truth 相矛盾的状态

## 核心 P1 必须关闭

必须通过真实可见 UI 完成：

1. 从 `/` 进入正常新产品
2. 新建厦门 Journey
3. 三步创建流程
4. 找到“AI 帮我规划”
5. 输入自然语言需求
6. 看到真实/诚实规划进度
7. 比较候选方案
8. 采用一个方案
9. 查看多日行程
10. 查看活动详情
11. 查看 / 选择住宿
12. 地图显示正确城市或诚实空状态
13. 问 Copilot “鼓浪屿好玩吗”
14. 不出现 REQUEST_PLACE_SEARCH
15. 打开预订/钱包不白屏
16. 后端断开后可恢复
17. GPS 拒绝后仍能规划
18. Recovery/HARD 状态不能被前端假装消失
19. Live Journey 能解释 disruption 与推荐调整
20. 中文 -> 英文 -> 中文不破坏当前 flow

## 导航必须是

今天 / 行程 / 地图 / Copilot / 我的

## Morning READY 的最低叙述

EAC 必须能够真实写出：

“我从全新浏览器打开 CityNexus，没有输入隐藏 URL。我创建了厦门行程，告诉 AI 我的需求，看到了规划过程，比较并采用方案，查看多日行程和正确的厦门地图，询问了鼓浪屿，进入住宿与预订，模拟后端/GPS/AI故障后仍可恢复，并在旅途中看到了可理解的动态重规划。”

这句话如果不是真的：
不能 READY。
