# Autonomous Product Lab Cycles

Complete FIVE cycles minimum.

Each cycle:

1. use the app fresh;
2. choose one persona/problem;
3. identify the highest-impact P0/P1;
4. reproduce;
5. locate root cause;
6. fix;
7. add regression/E2E evidence;
8. rerun;
9. save screenshots;
10. write one report:
    `AUTONOMOUS_CYCLE_1.md` ... `AUTONOMOUS_CYCLE_5.md`

Suggested cycle themes:

Cycle 1:
First-time usability and visual hierarchy.

Cycle 2:
Booking / hotel / commitment consistency.

Cycle 3:
Copilot and natural-language traveler actions.

Cycle 4:
Live disruption and recovery.

Cycle 5:
Failure states, navigation resilience and mobile polish.

If one theme is already clean, choose another real traveler problem.

Do not invent unrelated architecture.
