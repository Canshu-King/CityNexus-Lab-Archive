# Required end-to-end runs

After implementation, complete at least these SIX distinct browser runs.

## Run 1 — canonical Xiamen
Normal 3–5 day Xiamen trip.

## Run 2 — budget traveler
Low but plausible budget.
Verify budget warnings and hotel choices.

## Run 3 — long trip
Long Xiamen stay.
Verify week/day navigation and no giant day-chip strip.

## Run 4 — booking-first traveler
Create/import a booking before full planning.
Verify commitment integration.

## Run 5 — disruption traveler
Target a mutable real Xiamen POI.
Verify material replan and UI accept.

## Run 6 — degraded services
AI unavailable + provider unavailable + GPS denied in separate subcases.
Verify honest recovery.

Each run must record:
- journey_id;
- viewport;
- start/end timestamp;
- key actions;
- failures;
- fixes made afterward.

At least three runs must be at 390x844 or Xiaomi-like mobile width.
