# MORNING HANDOFF REQUIREMENTS

The morning package must let an independent reviewer answer these questions
without guessing:

1. What actually changed?
2. Which files changed?
3. Which visible traveler tasks now complete?
4. Which tests prove backend truth?
5. Which browser traces prove user flow?
6. Which screenshots prove mobile UX?
7. What remains blocked?
8. Is the product ready for Xiaomi 13 Ultra testing?

Do not hide unresolved issues behind aggregate pass counts.

Include explicit statements for:
- DeepSeek success path tested or not;
- provider success path tested or not;
- same-Xiamen visible chain completed or not;
- hotel->replan chain completed or not;
- booking import completed or not;
- Activity Detail real coordinates verified or not;
- known-free rendering verified or not;
- offline/GPS/AI failure states verified or not.

A reviewer must be able to distinguish:
- implemented;
- simulated;
- externally blocked;
- not attempted.
